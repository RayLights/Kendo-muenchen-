# Trainer-Fotos

Lege hier die Portraitfotos der Trainer:innen ab – sie ersetzen dann
**automatisch** die Platzhalter-Avatare (Initialen) auf der Website.

| Person          | Dateiname (genau so)   |
| --------------- | ---------------------- |
| Julia Jonentz   | `julia-jonentz.jpg`    |
| Sascha          | `sascha.jpg`           |
| Dance Yokoo     | `dance-yokoo.jpg`      |

- Am besten **quadratisch** zuschneiden (Portrait), mind. 600 × 600 px
- Formate: `.jpg`, `.png`, `.webp` (Dateiname dann in `lib/site.ts` anpassen,
  Feld `photo`)
- Datei < 500 KB halten (z. B. via [squoosh.app](https://squoosh.app))

> Das im Chat hochgeladene Foto lässt sich technisch nicht direkt übernehmen –
> bitte die Bilddatei hier mit dem passenden Namen oben ablegen.
> Bitte nur Fotos verwenden, für die das Einverständnis der Person vorliegt.
