# Bilder / Galerie

Lege hier Fotos vom Training, von Wettkämpfen oder Lehrgängen ab – sie
erscheinen dann **automatisch** in der Galerie-Sektion der Website.

- Unterstützte Formate: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`
- Empfehlung: querformat, mind. 1200 px breit, pro Datei < 1 MB
  (z. B. mit [squoosh.app](https://squoosh.app) verkleinern)
- Dateinamen werden alphabetisch sortiert – mit `01-…`, `02-…` lässt sich die
  Reihenfolge steuern.

Solange hier keine Fotos liegen, zeigt die Galerie stilvolle Kendo-
Illustrationen und einen Link zu Instagram.

> Bitte nur Bilder verwenden, an denen der Verein die Rechte hat und für die
> ggf. das Einverständnis der abgebildeten Personen vorliegt (DSGVO).
